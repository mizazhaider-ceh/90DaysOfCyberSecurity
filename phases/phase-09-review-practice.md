# Phase 9: Review and Guided Practice

This is your consolidation week. The first six days move you onto real training platforms like TryHackMe, HackTheBox, and picoCTF, where you practice against live targets and write down every step. The final day is a timed session that shows exactly what slows you down so you can fix it before Phase 10.

## Day 78: TryHackMe networking and web rooms
- **Learn:** TryHackMe runs guided "rooms" on real virtual targets, and the beginner path starts with networking basics (IP addresses, ports, protocols) and web basics (how a browser talks to a server).
- **Do:** Create a free account at https://tryhackme.com, then complete the rooms "Intro to Cyber Security" and "How The Web Works" from the start.
- [ ] Done: I finished both rooms and can explain what a port and a URL path are in my own words.

## Day 79: TryHackMe Linux and Burp Suite rooms
- **Learn:** Linux fundamentals teach the commands you will use on almost every target (listing files, reading permissions, finding processes), and Burp Suite is the standard tool for intercepting and changing web requests.
- **Do:** Complete the TryHackMe rooms "Linux Fundamentals Part 1" and "Burp Suite: The Basics", writing notes on every command and tool feature that is new to you.
- [ ] Done: I have notes on at least 10 Linux commands and the steps to intercept a request in Burp Suite.

## Day 80: HackTheBox Starting Point, first machines
- **Learn:** HackTheBox gives you full virtual machines to attack, and the Starting Point track is built for beginners, with each machine teaching one clear idea at a time.
- **Do:** Create a free account at https://www.hackthebox.com, connect to the Starting Point machines, and work through the first two machines, documenting every command you run and what it shows you.
- [ ] Done: I completed two Starting Point machines and have step-by-step notes for each one.

## Day 81: HackTheBox methodology practice
- **Learn:** Good testers follow the same loop every time: recon (what is out there), enumeration (what runs on it), exploitation (getting in), documentation (writing it all down so you can repeat it).
- **Do:** Continue through the next two Starting Point machines, and for each one write a short note under the four headings recon, enumeration, exploitation, and documentation before moving on.
- [ ] Done: Both machines have my notes organized under recon, enumeration, exploitation, and documentation.

## Day 82: Revisit your weakest days
- **Learn:** The fastest way to close gaps is to redo the tasks that were hard the first time, now that you have more practice behind you.
- **Do:** Pick the two days from Phases 1 to 8 that felt hardest, redo their full hands-on tasks, and write down what feels easier this time and what still confuses you.
- [ ] Done: I redid two weak days and have a short note on what improved and what still needs work.

## Day 83: picoCTF challenges
- **Learn:** CTF (capture the flag) challenges are small puzzles that test one skill at a time, like finding a hidden file, decoding a string, or exploiting a simple web page, which is perfect review for everything you learned so far.
- **Do:** Go to https://picoctf.org, create a free account, and solve at least 3 challenges in categories you already know (such as General Skills or Web Exploitation), writing down the steps for each solve.
- [ ] Done: I solved at least 3 picoCTF challenges and recorded how I solved each one.

## Day 84: Timed practice session
- **Learn:** Working against the clock exposes habits that waste time, like re-running commands you already ran or forgetting the note that had the answer, which is exactly what a real assessment punishes.
- **Do:** Pick any 3 labs you have done before, redo each one with a timer running, then write down for each lab what slowed you down and one change you will make to be faster next time.
- [ ] Done: I timed all 3 labs and have a written list of what slowed me down plus my fixes.
