# Learn: Curated Resources

This is the resource shelf for your 90-day cybersecurity plan. Every link below is a free, trusted resource that students actually use to learn, practice, and get hired in cybersecurity. Work through the sections in order, and bookmark the ones you will return to again and again.

## Networking

- Professor Messer, watch the Network+ playlist on his channel (https://www.youtube.com/@professormesser): free, exam-grade video lessons that cover every networking concept a security student needs first.
- Practical Networking: a YouTube channel with clear, hands-on videos on subnets, routing, and packet analysis.
- Wireshark docs (https://www.wireshark.org/docs/): the official documentation for the most-used packet analyzer, great for learning capture filters and display filters.

## Security Foundations

- CyberChef (https://gchq.github.io/CyberChef/): a free web tool for decoding, encoding, and analyzing data, useful in almost every CTF and incident.
- MITRE ATT&CK (https://attack.mitre.org): the industry-standard map of how attackers behave, from initial access to data theft. Learn to read its techniques and tactics.

## Linux

- Linux Journey (https://linuxjourney.com): short, friendly lessons that take you from the basic command line to users, permissions, and networking.
- OverTheWire Bandit (https://overthewire.org/wargames/bandit/): a game of Linux puzzles played over SSH, one of the best ways to make the command line stick.

## Python

- Python docs (https://docs.python.org/3/): the official reference, the fastest place to check how a module or function works.
- Automate the Boring Stuff (https://automatetheboringstuff.com): free book that teaches Python through small, practical scripts, perfect for security automation.
- freeCodeCamp (https://www.freecodecamp.org): free interactive coding lessons and certifications for Python and much more.

## Web Hacking

- PortSwigger Web Security Academy (https://portswigger.net/web-security/): free academy with lessons and labs for every major web vulnerability, the gold standard for web security learning.
- OWASP Top 10 (https://owasp.org/www-project-top-ten/): the ten most critical web application risks, explained with real examples. Learn this list before you touch a target.
- Burp Suite Community (https://portswigger.net/burp/communitydownload/): the free version of the standard web proxy tool, used in almost every web hacking lesson.
- PayloadsAllTheThings (https://github.com/swisskyrepo/PayloadsAllTheThings): a huge public collection of test payloads for injection, file uploads, and bypass techniques.
- HackTricks: a community-written book of hacking techniques and commands, great as a quick reference during labs.
- PenTrix VulnLab (https://github.com/mizazhaider-ceh/PenTrix-VulnLab): a practice lab web app by Muhammad Izaz Haider for learning real web exploitation in a safe environment.

## Practice Platforms

- TryHackMe (https://tryhackme.com): beginner-friendly guided rooms for networking, Linux, and hacking, with a free tier.
- HackTheBox (https://www.hackthebox.com): harder, more realistic machines and challenges for when you are ready to level up.
- picoCTF (https://picoctf.org): a free CTF competition site by Carnegie Mellon, great for practicing with puzzles and a clear progression.
- VulnHub (https://www.vulnhub.com): free downloadable vulnerable virtual machines to practice penetration testing offline.

## SIEM and Blue Team

- Elastic (https://www.elastic.co): the company behind the Elastic Stack (Elasticsearch, Kibana), used to build free SIEM labs at home.
- Sigma rules (https://github.com/SigmaHQ/sigma): a public collection of detection rules you can use in a SIEM, great for learning how analysts detect attacks.
- LetsDefend (https://letsdefend.io): a blue team training platform with SOC analyst simulations and guided incident cases.

## Cloud

- AWS free tier (https://aws.amazon.com/free/): a free account with limited AWS services, useful for learning cloud basics and building small labs.
- Microsoft Learn (https://learn.microsoft.com): free Microsoft learning paths for Azure, security, and identity topics.
- Google Cloud (https://cloud.google.com): Google's cloud platform, good for learning cloud fundamentals and trying the free tier.

## Git

- Learn Git Branching (https://learngitbranching.js.org): an interactive visual game that teaches Git branching faster than any tutorial.
- Git docs (https://git-scm.com/doc): the official Git documentation and the free Pro Git book.
- GitHub docs (https://docs.github.com): official guides for GitHub, from your first repository to pull requests and Actions.

## Career

- LinkedIn (https://www.linkedin.com): the professional network where security recruiters look for junior talent. Keep your profile updated as you learn.
- GitHub: your public portfolio. Push your lab writeups, scripts, and projects so employers can see your work.
- Resume and interview prep: write a short resume early and keep improving it as you finish labs, so you are ready when opportunities appear.

## YouTube Educators

- NetworkChuck (https://www.youtube.com/@NetworkChuck): energetic beginner-friendly videos on networking, Linux, and security certifications.
- IppSec (https://www.youtube.com/@ippsec): detailed walkthroughs of HackTheBox machines, showing real methodology step by step.
- LiveOverflow (https://www.youtube.com/@LiveOverflow): deeper videos on hacking concepts, binary exploitation, and how attacks really work.
- John Hammond (https://www.youtube.com/@_JohnHammond): CTF and malware analysis walkthroughs with clear, calm explanations.
- The Cyber Mentor (https://www.youtube.com/c/TheCyberMentor): course-quality lessons on ethical hacking and penetration testing from Heath Adams and the TCM Security team.

## How to Use This Page

Start with the Networking and Linux sections, because everything else builds on them. When a lab or lesson mentions a tool or concept you do not know, come back here and find the resource that explains it. Bookmark this page and treat it as your study library for all 90 days.
